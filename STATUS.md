## What was built

A complete beginner handbook for verifying AI-generated claims before publishing,
delivered in two formats from a single `docs/` source of truth:

1. **Markdown manual (`docs/`)**
   - `index.md` — landing page: audience, 60-second version, reading paths, how it
     relates to the sibling guides (when-ai-gets-it-wrong, spot-fake-media,
     study-smarter).
   - `01-why-confident-seeming-sources-can-be-invented.md` — why fluent text is not
     truth, the anatomy of invented citations, the six claim types AI invents most,
     the mindset shift ("claim generator, not fact supplier").
   - `02-the-claim-chasing-workflow.md` — 7-step verification workflow for essays,
     posts, and book chapters: freeze draft → sweep for claims → triage A/B/C →
     confirm sources personally → interrogate the AI → fix/hedge/cut → claim ledger.
   - `03-honest-phrasing-for-uncertain-facts.md` — hedging ladder plus word-for-word
     phrasebook by situation (fuzzy details, unsourced, outdated, contested,
     simplified, unknown), three phrasing rules, before/after examples.
   - `04-printable-source-check-worksheets.md` — five printable worksheets:
     Draft Freeze & Claim Sweep, Citation Test (4 checks), Claim Ledger,
     Final Sweep Checklist, Hedge Checklist — matching the workflow step for step.

2. **Static HTML site (`site/`)**
   - Five styled, linked pages plus `styles.css` — warm, book-like design,
     chapter pager, print-friendly worksheets preserved as code blocks.
   - Generated by `build.py`, a dependency-free Python 3 markdown→HTML renderer
     (headings, tables, lists, blockquotes, code fences, bold/italic, links).

**Supporting files:** `README.md` (credits Asdale Dynamics, LLC), `LICENSE`
(MIT, exact line "Copyright (c) 2026 Asdale Dynamics, LLC"), `tests/` (17-test
verification suite), `.gitignore`.

## How to run it

```shell
python3 build.py                          # rebuild site/ from docs/
python3 -m unittest discover tests -v     # run the 17-test suite
python3 -m http.server --directory site   # optional: serve the site
# ...or just open site/index.html directly in a browser
```

No external packages, no network, no secrets. Python 3.9+ only.

## Known gaps

- `build.py` is a deliberately minimal markdown renderer: it supports the
  constructs used in these docs (headings, tables, lists, nested quote
  paragraphs, fenced code, inline styles, links). It does not attempt full
  CommonMark coverage (e.g. nested lists, footnotes, raw HTML passthrough).
- No anchor links within pages (cross-references are page-level only).
- Worksheets are print-friendly but not tuned for specific paper sizes beyond
  sensible browser defaults.
- The sibling guides mentioned (when-ai-gets-it-wrong, spot-fake-media,
  study-smarter) live in their own projects and are referenced, not included.
