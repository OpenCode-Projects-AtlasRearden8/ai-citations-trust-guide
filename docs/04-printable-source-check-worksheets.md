# Chapter 4: Printable Source-Check Worksheets

*Work on paper, off-screen, with a pen. These match the Chapter 2 workflow step for step.*

---

## How to use these worksheets

1. Print this chapter (or copy a worksheet into your notes app and fill it there).
2. Run [the Claim-Chasing Workflow](02-the-claim-chasing-workflow.md) and fill each worksheet at its matching step.
3. Keep completed sheets with your draft — they're your verification record.

**Printing tip:** In your browser: File → Print. Choose portrait, default margins. Worksheet 3 works best in landscape; try `Ctrl+P → More settings → Paper size: Letter → Layout: Landscape`.

*Step 1–2: Freeze your draft and mark every checkable claim.*

```
---------------------------------------------------------------
 #  | Claim (short quote)         | Type (see key) | Tier (A/B/C)
---------------------------------------------------------------

  3  |                             |                |
  4  |                             |                |
  5  |                             |                |
  6  |                             |                |
  7  |                             |                |
  8  |                             |                |
  9  |                             |                |
 10  |                             |                |
---------------------------------------------------------------
Continue on a second sheet for longer drafts.

TYPE KEY:  CIT=citation   NUM=statistic   DATE=timeline
           NAME=person/org   QUOTE=direct quote   SPEC=product/law/event
```

**Rules reminder:** every QUOTE and every NUM is automatically Tier A.
A common 1,000-word AI-assisted draft yields **10–25 claims**; if you found fewer than 5, you probably swept too fast.

## Worksheet 2: Citation Test (one per source)

*Step 4: For every "a study/research/source says" claim, run the four checks.*

```
Claim #: ____   My draft's wording: __________________________________

---------------------------------------------------------------
 1. THE PAPER EXISTS                                   [ pass | fail ]
    Title found: ______________________________________________
    Authors: __________________________________________________
    Venue + year: _____________________________________________
    Where I found it (Scholar / PubMed / other): _______________

 2. IT SAYS WHAT'S CLAIMED                             [ pass | fail ]
    Relevant sentence(s), in my words:
    ___________________________________________________________

 3. THE DETAILS MATCH                                  [ pass | fail ]
    Year: draft ______ vs source ______
    Sample/test size: draft ______ vs source ______
    Stat: draft ______ vs source ______
    Direction of effect:  [ same | different ]

 4. IT'S APPROPRIATE                                   [ pass | fail ]
    Source type: journal / report / interview / dataset / other
    Is a preprint or outlier carrying more weight than it should?
                                                  [ no | YES-PROBLEM ]

RESULT:  [ VERIFIED — include ]  [ PARTIAL — rewrite, details above ]
         [ UNVERIFIABLE — hedge or cut ]  [ CONTRADICTED — delete ]
```

**Any single "fail" = the citation fails.** There is no partial credit — a 3-of-4 citation is a fake citation with better odds.

## Worksheet 4: Final Sweep Checklist

*Last pass before you publish. Yes = done, for real.*

```
[ ] Every direct quote traced to a source I personally opened
[ ] Every statistic tied to a real, dated source
[ ] Every citation passed all 4 checks (Worksheet 2)
[ ] Every named person/org confirmed to exist and match
[ ] Every "always/never/all/none" either proven or right-sized
[ ] Hedges (Worksheet 5 below) applied where verification failed
[ ] Timestamps added ("as of Nov 2026") for fast-moving facts
[ ] Claim ledger filled for every A-tier claim
[ ] Featured new claims from final edits re-swept
[ ] I could answer "where did this come from?" for any sentence

PRE-PUBLISH CALL:  [ READY ]   [ READY AFTER: ______________ ]   [ NOT YET ]
```

## Worksheet 5: Hedge Checklist (quick reference)

*For claims you couldn't verify. Full phrasebook in [Chapter 3](03-honest-phrasing-for-uncertain-facts.md).*

```
CLAIM FEELS...          →  HEDGE PATTERN (write once, reuse forever)
Fuzzy on details        →  "Studies of X have found that many Y rarely Z"
Plausible but unsourced →  "Based on my own experience..." / "Anecdotally..."
Might be outdated       →  "As of my last check (___/___/____)..."
Contested               →  "There's genuine debate on this..."
Simplifying a topic     →  "The short version is... [source] has more"
I just don't know       →  "I don't know."  (Then: offer the next step instead)
```

Right-sizing strip — circle any you find in your draft, then shrink them:
*always · never · all · none · everyone · no one · proves · shows that · the first · the best · official · guaranteed*

---

## A note on staying honest with yourself

The worksheets only work if the marks in the boxes are true. If a source check took 90 seconds of skimming, write that; if you stopped searching after two attempts, write that. The point isn't a pretty sheet — it's knowing, five minutes before publication, exactly how solid each sentence is.

Verification isn't the tax you pay for using AI. It's the craft that makes the writing yours.
