# Trust-but-Verify Manual for What AI Tells You

A beginner-friendly guide to checking AI-generated claims before publishing: essays, posts, newsletters, book chapters. Explains why confident-seeming sources get invented, walks through a step-by-step **claim-chasing verification workflow**, gives honest phrasing for uncertain facts, and includes printable source-check worksheets.

Part of **The Massive AI Manual** by Dylan Asdale — AI explained "like a friend would": plain English, step by step, never condescending.

## What's inside

| File | Contents |
| --- | --- |
| `docs/index.md` | Landing page: who it's for, the 60-second version, reading paths |
| `docs/01-why-confident-seeming-sources-can-be-invented.md` | How and why AI invents citations, quotes, and stats |
| `docs/02-the-claim-chasing-workflow.md` | The 7-step verification workflow for any draft |
| `docs/03-honest-phrasing-for-uncertain-facts.md` | Word-for-word hedging language that keeps credibility |
| `docs/04-printable-source-check-worksheets.md` | Five printable worksheets matching the workflow |
| `site/` | The same guide as a static HTML website (generated by `build.py`) |

## Read it

- **In the browser:** open `site/index.html` directly, or serve locally with `python3 -m http.server --directory site`
- **As markdown:** start at `docs/index.md` — but the worksheets print best from the HTML pages

## Build & test

```shell
python3 build.py                          # regenerates site/ from docs/
python3 -m unittest discover tests -v     # runs the verification suite
```

Requirements: Python 3.9+ and nothing else — no external packages, no network.

The test suite verifies that the build succeeds, every generated page exists, all internal links resolve, the LICENSE contains the exact required copyright line, the README credits the publisher, and no secret-looking strings appear in tracked files.
